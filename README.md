# 막장 로판 게임관 · AI 게임팩

ChatGPT·Gemini·Claude에 게임팩 파일을 넣고 **「게임 실행해줘」**라고 하면 AI가 게임마스터가 되어 진행하는 채팅형 막장 코믹 로판 게임 5종.

- 사이트: https://shiningshuri.github.io/rofan-game-pack/
- 게임팩: `dist/막장로판_게임팩.html` (파일만 따로 보내도 동작 — 이미지는 이 사이트 주소에서 불러옴)

## 수정·재빌드
설정은 `pack_core.md`에서 고치고:

```
python build.py https://shiningshuri.github.io/rofan-game-pack/
```
